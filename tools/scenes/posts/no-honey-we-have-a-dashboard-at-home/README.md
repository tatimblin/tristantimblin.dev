# no-honey-we-have-a-dashboard-at-home

The post art for *No Honey, We Have a Dashboard at Home*: a module sheet in
simple shapes. Nothing is drawn literally — four plain rectangles stand in
for the four jobs the fleet dashboard did (list cars, show a digital twin,
run actions, tail signals). On the left they are the dashboard: separate
dashed pages running off the plate, struck through in coral. In the middle
they dock into one heavy frame, the editor: the list a solid column, the
twin a pane holding the bold `stripe-disc`, the actions a key, the signals
a green bar. The column carries the post's count — 0 frontends (the coral
numeral), 0 deploy pipelines, 0 auth systems — the route (Yext in 2022,
`.yextrc`, multi-tenant auth, to Fisker) and the dock's meter.

The motion is `steps`, four beats: each job lands in the editor, a pip
lights, and its mapping (LIST → TREE VIEW … SIGNALS → TERMINAL) reads as a
now-mark. The still is all four docked, 4/4.

`scene.ts` is the source; `bun run scenes:bake` writes
`src/content/txt/no-honey-we-have-a-dashboard-at-home.svg`. Drawn from the
kit and the stripe-disc recipe: no external data, no credit.
