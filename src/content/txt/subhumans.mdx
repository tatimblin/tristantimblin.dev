More of the workday now happens inside an agent session, and it can get lonely. Being heads-down with an agent while a coworker sits a few feet away isn't how most of us want to work. The work moves fast. An API contract can change mid-flight, making communication the bottleneck.

sub-human puts coworkers and friends back in the loop, so pivots reach everyone as they happen, without interruption. As teammates, you keep your own workspace, login and session. sub-human connects those sessions remotely using the same machinery Claude Code already uses for subagents.

Working together might now look like a planning session, followed by divvying up tasks, and freely pivoting.

In our example, when Jess changes course, Tristan doesn't get a ping. A message goes out to his Claude, and it builds against the new contract. It's then up to his agent to inform him or not.

## What's in the room

- **Group consensus.** Plans go to the room for versioned edits, then everyone signs off in their own plan view.
- **Shared task list.** Everyone claims work from Claude Code's native task list.
- **Agents that talk to each other.** Claudes pass relevant changes to the right person, or ask someone else's session for an update.

There's no required workflow. Join a room and tell your Claude how you'd like to work.

## How it's built

sub-human doesn't add a workflow of its own. It extends a few Claude Code features and adds a networking layer between sessions.

- **Native to Claude Code.** Rooms use the messaging, plans and task list Claude Code already gives subagents.
- **Not a shared session.** Nobody types into someone else's Claude. Each person keeps their own files, permissions and account.
- **No server.** A room lives on the machine that opened it. Other machines reach it over SSH or Tailscale.

## Spend the time together

With agents doing more of the typing, we get time back for the parts that were always better together: pairing on the hard problems from design through implementation. The coworker a few feet away is still the fastest way to catch a bad idea. sub-human just makes sure your Claude knows they're there.

## Try it with a friend

Install the [plugin](https://github.com/tatimblin/sub-human) from any Claude Code session:

```claude-code title="Install"
/plugin marketplace add tatimblin/sub-human
/plugin install sub-human@sub-human
/reload-plugins
```

You need Claude Code 2.1.292+ and Node 22.18+. sub-human is in beta: it runs on macOS and Linux only.

Once it's installed, run `/sub-human` to open a room, then `/sub-human invite` for a join command and a PIN to share.
